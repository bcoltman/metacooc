# Changelog

## 0.1.0 — 2026-08-26

First public release of MetaCoOc for co-occurrence, association, and
community-structure analysis of microbial metagenomes.

- Adds published R226 Ingredients data-release selection and verification.
- Provides compact summary and detailed analysis outputs.
- Provides analysis-specific association and co-occurrence plots.
- Includes CLI workflows, Python entry points, and user documentation.
