# MetaCoOc

MetaCoOc finds associations and co-occurrences between microorganisms in shotgun metagenomes. It works with the taxonomic profiles themselves, but also lets you define a cohort from a biome, metadata term, or focal taxon and compare it with a clearly defined background.

This guide is written for microbial ecologists and computational biologists. You can start with the copy-and-paste commands in the quick setup, then use the advanced pages when you need to choose a null model, change filtering, or work with large outputs.
